# Stellar Burgers UI autotests

Проект содержит UI-автотесты для веб-приложения Stellar Burgers.

## Описание проекта

Автотесты проверяют основные пользовательские сценарии:
- регистрацию пользователя;
- авторизацию пользователя;
- переходы между страницами;
- работу личного кабинета;
- выход из аккаунта;
- переходы между разделами конструктора.

## Используемые технологии

- Python
- Selenium WebDriver
- Pytest
- Page Object Model

## Покрытые тестами сценарии

### Регистрация
- Успешная регистрация пользователя.
- Проверка регистрации с некорректным паролем.

### Авторизация
Проверяется вход:
- через кнопку «Войти в аккаунт» на главной странице;
- через кнопку «Личный кабинет»;
- через кнопку «Войти» в форме регистрации;
- через кнопку «Войти» в форме восстановления пароля.

### Личный кабинет
Проверяется:
- переход в личный кабинет;
- переход из личного кабинета в конструктор;
- переход по логотипу Stellar Burgers;
- выход из аккаунта.

### Конструктор
Проверяется переход между разделами:
- «Булки»;
- «Соусы»;
- «Начинки».

Проект выполнен с использованием Selenium WebDriver и Pytest.
